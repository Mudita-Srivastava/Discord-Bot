🤖 Discord AI Bot: 
A custom Discord bot that leverages the Google Gemini API to provide concise, intelligent responses to user messages within Discord channels, ensuring message length compliance.

✨ Features
Intelligent Response: Integrates the high-performance Gemini 2.5 Flash model for fast, relevant, and helpful responses to any text prompt.

Discord Compliance: Automatically enforces a 2000-character (500-token) limit on all bot responses.

Simple Setup: Uses discord.js and @google/generative-ai for straightforward installation and deployment.

Ready for Scaling: Configured for the most current Gemini API structure, allowing for easy expansion to conversation history or tool use.
